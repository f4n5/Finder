API instructions (wire this up)

Point the cleaner at your backend. The frontend already posts multipart FormData to /api/clean. Implement that route on your server / serverless function. Below is the contract and a minimal handler sketch.

// === REQUEST === // POST /api/clean // Content-Type: multipart/form-data // fields: // file : binary (.exe / .dll / .zip) // mode : "malware" | "key" // name : original filename // === RESPONSE (JSON) === { "ok": true, "mode": "malware", "removed": [ "discord_webhook", "clipboard_hook", "startup_persistence" ], "kept": [ "injection_stub", "script_engine", "ui_module" ], "download_url": "https://your-cdn/cleaned/abc123.exe", "report": "Stripped 3 malware modules. Injection path untouched." } // === EXAMPLE NODE HANDLER (Express + OpenAI / local LLM) === app.post('/api/clean', upload.single('file'), async (req, res) => { const mode = req.body.mode; // "malware" | "key" const buf = req.file.buffer; // 1. extract / disasm relevant sections // 2. build prompt for the model: const prompt = mode === 'malware' ? `Identify and list offsets of stealers, webhooks, persistence. Do NOT touch injection, DLL mapping, or Luau VM code. Return JSON list of patches (offset, length, replace_with_nop).` : `Identify key-check / license HTTP / HWID lock routines. Return patches that force success path. Leave inject alone.`; // 3. call your model (OpenAI, Claude, local GGUF, etc.) const patches = await callModel(prompt, buf); // 4. apply patches, write new binary, upload to storage const cleaned = applyPatches(buf, patches); const url = await uploadToStorage(cleaned); res.json({ ok: true, mode, removed: patches.map(p => p.label), kept: ['injection_stub', 'script_engine'], download_url: url, report: `Applied ${patches.length} patches.` }); }); // === FRONTEND CONFIG === // Change CLEAN_API in the script tag below to your endpoint. // const CLEAN_API = 'https://your-api.example.com/api/clean';
